## 📖 Overview

**Urban Shopy** is a full-stack MERN e-commerce platform built from scratch. It features a premium, minimal storefront with a complete shopping flow — from product discovery to Cash on Delivery checkout.

This project demonstrates:

- **Modern frontend architecture** with React 18, TypeScript, Redux Toolkit, and Tailwind CSS
- **REST API backend** with Express, MongoDB, JWT authentication, and password hashing
- **Production deployment** on Render (frontend static site + backend web service)
- **Clean monorepo structure** with separated client and server workspaces

## 🚀 Local Setup

Follow these steps to run **Urban Shopy** on your machine in under 5 minutes.

### Prerequisites

Make sure you have the following installed:

| Tool | Minimum Version | Download |
|:---|:---|:---|
| **Node.js** | v18 or higher | [nodejs.org](https://nodejs.org) |
| **npm** | v9 or higher | *(comes with Node.js)* |
| **Git** | latest | [git-scm.com](https://git-scm.com/downloads) |
| **MongoDB** | local or Atlas | [mongodb.com/atlas](https://www.mongodb.com/atlas) |

> ✅ **Recommended:** Use **MongoDB Atlas** (free cloud) so you don't need to install MongoDB locally.
